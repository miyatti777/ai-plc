# Codex adapter: plc-brief

実行前に [Codex実行環境の読み替え](../references/codex-runtime.md)を読む。正本の手順・入力・モードは実行時に読み込み、以下は環境差分として適用する。

1. リポジトリルートの `.claude/skills/plc-brief/SKILL.md` を最後まで読み、その手順を正本として実行する。
2. 読取専用で目的・出来た成果・使い方・期待効果をつながった文章で説明し、重要な残件/不確実性を添えて止まる。通常は工程表や管理記録を列挙しない。説明対象のintent/backlog/成果物/Registryを変更しない。 用語と前提の補足・段落と短い見出し・要点だけの太字、必要場面の図解提案、本人希望時の対話/クイズは正本の出力ルールに従う。
   公開版には HTML モード（図解スライド）は無い。HTML を求められたら、文章の説明で返し、HTML は公開版に無いと伝える。

3. 案内する `/plc-*` はCodexでは同名の `$skill` 指定に読み替える。スキル未掲載なら共通文書に従い実在するSKILL.mdの絶対パスで案内する。
4. 正本が欠ける場合は実行せず、欠落内容を報告する。
