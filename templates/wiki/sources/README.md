# sources/ — ソースサマリーページ

外部の1次ソース（記事・論文・書籍・動画・外部ドキュメント）を取り込んだら、**1ソース=1ページ**でここに要約を置く。概念ページ（wiki直下）への波及更新は、このサマリーページを起点に行う（RUL_plc_system §11）。

## 命名

`YYYY-MM-DD_[slug].md`（例: `2026-07-07_llm-wiki-connecting-knowledge.md`）

## テンプレート

```markdown
> 🏷️ **Type:** source
> **Origin:** [URL or 書誌情報]
> **Ingested:** YYYY-MM-DD
> **Tags:** [タグ]

# [ソースタイトル]

## 要約
[3-10行]

## 概念ページへの波及
- [[concept-slug]] — [何を追記したか1行]
```

## ルール

- サマリーページは取り込み後は原則不変（追記は概念ページ側で行う）
- 作業中に得た内部知見（外部ソースなし）はサマリーページを作らず、概念ページに直接追記でよい
