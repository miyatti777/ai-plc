# Daily Task

> 決まった日に繰り返すタスクを置くファイルです。/ppm-plan は、行の末尾のタグがその日に当たる行を WillDo の「5. Daily Task」に入れます。
> タグ: `[daily]` 毎日／`[weekly:月水金]` 書いた曜日（月火水木金土日）／`[monthly:1]` 毎月その日（その日が無い月は入りません）。
> タグの無い行は入りません。行の `:15` は見積の分です。見出しの名前は自由です。下の例は架空です。

## 毎日

- [ ] 社内の掲示を見る :15 [daily]
- [ ] 植木に水をやる :5 [daily]

## 毎週

- [ ] 週報を書く :30 [weekly:金]
- [ ] 郵便物を出す :10 [weekly:月水]

## 毎月

- [ ] 共用のプリンターの用紙を足す :10 [monthly:1]
