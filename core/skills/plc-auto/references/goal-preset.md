AI-PLC 自動完走（自己完結版）。この会話で扱っている AI-PLC Layer を、今の状態から最後まで完走する。対象は、この会話で直前に /01-collection〜/04-operation を実行した Layer か、直前に話題にした Layer。どちらも無ければ、この会話で頼まれた Goal で /01-collection から新しく作る。始める位置は Layer なら /03-construction へ）、construction.required が true で Agent 定義の無いタスクがあれば /03-construction から、それ以外は /04-operation から。順序は /01-collection → /02-inception →（construction.required が true のときだけ /03-construction）→ /04-operation。達成: その Layer の backlog の全タスクが completed（deferred・blocked は保留理由がログにあるもの）で、各 output が実在し、Phase 7 チェックリストと自動承認ログ（自動で選んだ判断の一覧）を表示する。または行頭に単独で「⛔ 自動完走を停止: <理由>」を表示する。進め方（各 plc-autoの専用入口: 利用者がこのSkillを明示実行し、native Goalへの設定成功とactiveを確認できた場合だけ自動承認を適用する。CodexではStage名を同名の $skill 指定へ読み替える。pipeline_variant: jev のLayerも通常版を使い、凍結中の -jev 実験版は使わない。Jev監視のopt-inは自動承認しない。並列作成委譲は適用中の許可・条件がある場合だけ。標準の独立reviewer検証は維持する。

ターン観測: 利用者入力またはGoal自動継続で始まるメインエージェントの応答1回を1ターンとし、ツール呼び出し・Stage遷移・reviewerを数えない。createdAtをrun IDにし、最初のLayer作成後に1、その後は同じrunのrefactoring_logから加算して、各応答開始を [plc-auto-turn] run=<createdAt> turn=<N> と1回記録する。同じ応答中の再呼び出しは加算しない。記録の欠落で正確に数えられなければその限界を示す。

native Goalの状態は実際のツール規約に従う。停止文だけでcompleteにしない。blockedは同じ障害が3回以上の連続Goalターンで再発し進捗不能の場合のみ、pausedは利用者の明示的な一時停止要求のみ。必要な作業が残っていないと確認できたときだけcompleteにする。
