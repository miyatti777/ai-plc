## Codex での扱い

Codex では上記の Stage 名を同名の `$skill` 指定へ読み替える。この本文を plc-auto の明示実行によって native Goal に設定し、その Goal が active である間だけ、ここに記載された範囲の自動承認を適用する。「最大60ターン」は Codex への実行指示であり、ネイティブの機械的なターン上限を設定したという意味ではない。
