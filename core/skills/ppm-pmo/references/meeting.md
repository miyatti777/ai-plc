# 責任者向け定例・判断メモ

`decision_brief.md`に以下を書く。空欄を都合よく埋めず「未確認、確認先」を記載する。

1. **今日判断してほしいこと**：どの案件間の何を決めるか。判断者/権限が未確認なら先に確認。
2. **根拠**：analysisの依存ID/資源ID/期間/共通要因。出典path・locator・revision、情報時点、暫定性。
3. **選択肢**：案ごとに案件A/B/Cへの影響、成立条件、追加確認、取り返しやすさ。確定日付や効果を勝手に作らない。
4. **決定記録**：未決/決定、決定者、権限範囲、日時、対象内容版。未決は案のまま。
5. **案件別次アクション**：案件/依頼内容/担当/期限（未確認なら未確認）/反映確認方法。
6. **次回へ**：未回答、未反映、古い情報の取得、前回決定の読戻し。

声かけ例：
- 案件PMへ「この見通しはいつ時点ですか。ほかの案件が待っている成果物なので、使える日を確認したいです」
- 資源担当へ「同じ週に3案件から合計9時間/日の依頼があります。上限8時間/日という理解で合っていますか」
- 責任者へ「A優先とB優先では待つ案件が変わります。納期条件を確認したうえで、どちらを優先するか決めていただきたいです」

AIが文案を作ることと、相手に実際に連絡したことは別。送信していなければ送信済みと書かない。
